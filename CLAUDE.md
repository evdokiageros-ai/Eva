# Workspace

This repository is my knowledge base for office work at Energy Shift B.V.
(administration). Each folder is one topic. Claude reads this file and the
`CLAUDE.md` in each topic folder at the start of every session.

## Folders

- `invoices/` – supplier invoices: questions, disputes, what each supplier charges for
- `contracts/` – contracts, indexation calculations, terms
- `emails/` – reusable email templates and sent drafts

## How to work here

- Save every finished piece of work (email, calculation, summary) in the folder
  for its topic, with a clear file name, e.g. `invoices/bluem/2026-10-email-F20266480.md`.
- After a task, add what was learned to that folder's `notes.md`
  (supplier facts, answers received, decisions made) so the next session can build on it.
- Before starting a task, read the topic's `notes.md` first.
- Emails: write in English, and add a Dutch version when the recipient is Dutch.
  Polite business tone. Sign as "[Your name], Energy Shift B.V. – Administration".
- To add a new topic, create a folder with its own `CLAUDE.md` and `notes.md`
  and list it above.
